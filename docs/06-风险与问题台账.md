## 4. AI 相关风险记录

> 记录 agent 协作中发生的典型问题，既是风险管理，也是研制总结"AI协作总结"一章的素材。

| 编号 | 现象 | 如何发现 | 如何纠正 | 对流程的改进 |
|---|---|---|---|---|
| AI-01 | agent 在开发日志初稿里**编造**了一句"agent 提议额外操作被否决"（实际未发生） | agent 交付前自查发现 | 删除该句并在日志中留痕说明 | 日志中出现"学生否决/修正"这类陈述时必须能对应到具体对话 |
| AI-02 | agent 用 ffmpeg 抽帧核对视频时，裁剪坐标**连续算错两次**（先裁到桌面线缆、再裁到塑料盒），浪费两次工具调用 | 查看抽帧图片发现区域里没有灯珠 | 改为整帧缩小后拼 4x3 九宫格定位 | 先看整帧定位，再裁局部；避免拿缩略图坐标线性外推 |
| AI-03 | agent 用"最饱和像素"判断灯色，被画面里常亮的绿色物体带偏，得出大量"绿/无法判定"的无效结论 | 结果与串口日志的 1s 节奏不符 | 改为整帧拼图 + 串口时间戳交叉验证 | 单一启发式判据不可靠时，必须换一种独立方法交叉验证 |
| AI-04 | agent 写证据文件时漏 `-Encoding utf8`，把中文写成 ANSI 乱码 | 复读文件发现乱码 | 删除重建并显式指定编码 | 写含中文的文件后必须回读校验编码 |
| AI-05 | agent 把"今天"推算成课程第 3 周（依据是工作重点与 T0 吻合），据此排出错误的里程碑日期 | 学生告知"今天是第六周周六" | 重排 M1~M5 日期并写入换算依据 | 涉及课程时间线的推算必须向学生确认锚点（第 1 周起始日或当前周次） |
| AI-06 | agent 用 `Select-String '必须'` 统计 manifest 待填项，因编码问题误报"剩余 0 项"，与实际的 15 项矛盾 | 前后两次检查结果不一致 | 改用 `PYTHONIOENCODING=utf-8` 重跑并核对 | 统计类结论如与上一次结果差异过大，必须复核命令本身是否可信 |
