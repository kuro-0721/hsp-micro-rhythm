## 1. 扫描范围与方法

扫描整个仓库（排除 `.git/` 与编译产物 `project/build_*/`）下的图片、音频、字体与二进制资源：

```powershell
Get-ChildItem -Recurse -File -Include *.png,*.jpg,*.jpeg,*.gif,*.bmp,
  *.mp3,*.wav,*.ogg,*.aac,*.ttf,*.otf,*.bin,*.pack |
  Where-Object { $_.FullName -notmatch '\\\.git\\|\\build_' }
```

## 3. 明确声明

- 本仓库**不包含** Phigros、Arcaea、Cytus、Deemo 或任何其他商业音游的曲目、谱面、插画、UI 贴图或字体。
- 内置谱面 `src/chart.c` 的 `s_builtin_chart` 是**按 120 BPM 规则自行生成的时间戳列表**（每音符间隔 500ms、4 轨轮转），不是任何已有曲目的谱面。
- 曲名「HSP RHYTHM」为项目自拟占位名，不对应任何商业作品。

## 4. P1 阶段的素材约束（提前声明，避免后续踩线）

REQ-008（TF 卡 MP3）与 REQ-009（命中音效）会引入音频素材，届时必须遵守：

1. 曲目只用**自制**（自己录音/自己合成）或**明确标注 CC0 / 公有领域**的音乐；
2. 音效同理，若使用素材站资源，须在本文档追加一行：文件名、来源 URL、许可协议、取得日期；
3. 每次新增素材后重跑第 1 节的扫描命令，并把结果更新到本文档；
4. 不得使用任何商业音游的音频、谱面或美术资源——这是课程学术诚信要求，也是 `docs/06` 风险台帐 R-05 的应对措施。
