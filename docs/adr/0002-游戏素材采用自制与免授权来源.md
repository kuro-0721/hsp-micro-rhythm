# ADR-0002: 游戏素材（曲目/谱面/美术）采用自制与免授权来源

- 状态：已采纳
- 日期：2026-10-10
- 决策人：kuro-0721　协助：GitHub Copilot（DeepSeek V4.1 Flash）
- 关联需求：REQ-105（素材版权合规）、REQ-008（TF 卡曲目与谱面）

## 背景

项目定位是「类似于 Phigros 的简化版音游」。玩法机制本身可以自由借鉴，但 **Phigros 的曲目、官方谱面、角色与美术素材受版权保护**，直接取用会带来两个后果：

1. 法律与学术诚信风险：把他人作品当作自己的交付物；
2. 课程评分风险：课程明确要求「不要伪造/借用他人成果」，素材来源不清会直接影响过程分。

同时，P1 要从 TF 卡加载曲目（MP3）与谱面，素材来源方式会决定：

- 谱面格式怎么设计（自制谱面可以自由定义时间戳精度与字段）；
- 是否需要在仓库内保存授权说明文件。

## 备选方案

| 方案 | 优点 | 缺点 | 对需求/风险的影响 |
|---|---|---|---|
| A. 直接使用 Phigros 的曲目与谱面 | 零制作成本、谱面质量高、演示效果好 | 侵犯版权；与课程学术诚信要求冲突；一旦被追问来源无法自证 | REQ-105 直接不通过，且存在评审风险 |
| B. 全部自制：自己录/合成曲目 + 自己写谱面 + 自己画美术 | 版权完全干净；谱面完全可控；过程本身就是项目工作量的一部分 | 制作耗时；曲子质量取决于本人的音乐能力 | REQ-105 可验证通过；谱面格式自由度最高 |
| C. 使用明确免授权（CC0/CC-BY）素材 + 自制美术 + 自制谱面 | 版权干净且省去作曲时间；仓库内留授权说明即可 | 需要逐个核对许可条款（署名/相同方式共享等），谱面仍需自己写 | REQ-105 通过；需在仓库保存许可与来源清单 |

## 决策

采用 **方案 B + C 组合：曲目用自制或明确免授权（CC0/CC-BY，附来源与许可），谱面与美术一律自制**。

理由：谱面是本项目要验证的核心数据（判定时刻、轨道、精度），必须自己可控，也正好是能体现工作量与理解的部分；曲目部分是纯素材，用免授权可以省时间，但**必须逐个记录来源与许可**，不能留下「不知道哪来的」文件。明确拒绝方案 A：拿别人的曲目和谱面来演示，等于把项目的核心内容外包给了一个被抄袭的对象，评审时也说不清。

## 后果

- 正面：素材来源可自证；谱面格式可以完全按判定需求设计（毫秒时间戳 + 轨号）；REQ-105 可被检查。
- 负面/代价：需要额外时间制作谱面与美术；若用 CC-BY 素材，需要在仓库或展示页保留署名。
- 需要同步修改：`docs/01` 第 5/7 节（约束）、`docs/02`（谱面格式与素材清单）、`docs/03`（REQ-105 的检查方法）、`manifest.yaml` 的 `design.key_decisions`；仓库内需有素材来源/许可说明文件（计划放 `docs/03` 或独立清单）。

## AI协作

agent 指出直接使用商业音游素材存在版权与学术诚信双重风险，并给出 A/B/C 三个备选与代价分析；学生确认采用 B+C 组合，并同意「曲目必须是自制或明确免授权」。agent 另外提出的「先做 P0 无声版、素材问题推迟到 P1 再处理」被学生接受，因此本 ADR 的素材清单在 P1 开始时补齐。
