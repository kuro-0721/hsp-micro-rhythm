## 遇到的问题与解决

> 报错/卡点 → 排查过程 → 根因 → 解决办法。没有就写“无”。重要的问题同步登记到 `06-风险与问题台账.md`。

1. **pyyaml 显示安装成功但导入失败**。现象：安装动作返回成功，但终端里 `python -c "import yaml"` 报 `ModuleNotFoundError: No module named 'yaml'`，`setup_course.py` 也仍然提示未安装 pyyaml。排查：`Get-Command python -All` 看到终端实际用的是 Microsoft Store 版 Python 3.11.9（`...\WindowsApps\python.exe`），用它执行 `python -m pip show pyyaml` 显示 Package(s) not found。根因：上一次安装落到了另一个解释器环境里，两边不是同一个 Python。解决：显式对终端这个解释器安装 `python -m pip install --user "pyyaml>=6.0"`，再 `import yaml` 验证通过。教训：本机上「报装成功」≠「终端能用」，装完必须用同一条命令链验证。
2. **setup_course.py 报告 SiFli SDK 环境未就绪**：`SIFLI_SDK` 未设置、找不到 `scons`、找不到 `arm-none-eabi-gcc`。根因：执行初始化的这个终端没有运行过 SDK 的 `export.ps1`；SDK 实际已装在 `e:\tool\SiFli-SDK\v2.5.1`。脚本明确说明这不影响仓库初始化，因此本次未处理，留到 T0 B 部分在已 export 的终端里用 `python scripts/check_env.py` 复查。
3. **`check_all.py` 的 manifest 检查输出乱码**：终端按 GBK 解码脚本的 UTF-8 输出所致，检查结论本身可读（26 处未填写）。暂不影响使用，先记录；若后续影响阅读再排查。
