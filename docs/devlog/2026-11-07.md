## 遇到的问题与解决

1. **`check_all.py --final` 报 manifest 三处证据路径不存在**：我原来把多个证据文件写成逗号分隔的单个字符串（`"a.log, b.log"`），校验脚本把整串当一个路径去找，自然找不到。解决：`evidence_path` 只填**主要**那一份，其余文件在 `agent_conclusion` 正文里点名。
2. **两条 `physical_verification` 条目被插错位置**：插入时的锚点落在了 `physical_verification_note: |` 之后，两条 `- item:` 处于块状标量（`|`）内部，被 YAML 当成说明文字吞掉——文件语法合法、`yaml.safe_load` 不报错，但列表里只有 13 条，新写的两条根本没进 `physical_verification`。解决：写脚本把这两条整体搬到 `physical_verification_note` **之前**，重新解析确认条目数 13→15、note 内不再含 `- item:`。**这个错误很危险**：如果没顺手核对条目数，就会交出一份「看着写了、其实没生效」的证据清单。
3. **git commit 被钩子拒绝两次**：正文里写了带尖括号的比较式（如 `p95<=34ms`），`check_commit_msg.py` 把 `<` 当成未替换的模板占位符直接拒绝。解决：正文改写成「不超过 34ms」这样的自然语言，不使用尖括号。
4. **`check_devlog` 报 2026-10-17 → 2026-10-25 间隔 8 天无提交**：这是历史事实（那段时间没有推进项目），按规则不能改 `check_*.py` 让它通过，也不能伪造提交或日志，只能在这里如实说明：**该间隔真实存在，原因是国庆后一周课程冲突、项目停摆**，属已知的、不做修饰的缺口。
5. **`check_all.py --final` 的固件编译一节显示 SKIP**：当前终端没有先执行 `export.ps1`（缺 `SIFLI_SDK` / `scons`），脚本按设计跳过而非判失败。我另外在 SDK 环境里单独编译过交付版（606,308 B，学生已上板确认），但这不等于 `--final` 里的编译检查真的跑过——**如实记录**：该项在无 SDK 环境的终端是 SKIP，需在已 export 的终端重跑才算真正通过。
