## 遇到的问题与解决

1. **没有 pandoc / pypandoc**：本机两个都没有，改用 python-docx 自写简易 md→docx 转换器
   （支持标题/表格/列表/引用/粗体/行内代码；不支持嵌套列表、图片、脚注——这两份文档刚好用不到）。
2. **页脚页码顺序错**：第一版把页码域插在前缀文字之前，会显示成「3 HSP RHYTHM … 第 页」。
   回读页脚 XML 子元素顺序才发现，改成「前缀 run → `fldSimple(PAGE)` → 后缀 run」。
3. **转换脚本写死路径**：生成第二份文档时只能复制脚本，改成命令行参数（`src dst 副标题 文档标题`），
   两份共用同一个脚本。
