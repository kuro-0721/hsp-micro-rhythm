# T0 环境与仓库

**目标**：准备好 SiFli SDK v2.5.1 开发环境，编译（有板则烧录）内置例程并看到 RGB 灯闪烁，初始化仓库、体验提交规范钩子，写出第一篇开发日志。　**时长**：约 2.5 小时（含 SDK 获取，视网速）

> 本仓库自带一个 SiFli SDK 工程，结构与官方例程一致：`project/`（`SConstruct`、`Kconfig`、`proj.conf` 等构建文件）+ `src/`（应用源码）。不需要再建工程。

## 前置软件

| 软件 | 要求 | 检查命令 |
|---|---|---|
| Git | 2.30+ | `git --version` |
| Python | 3.8+（仓库脚本用；SDK 自带独立 Python 环境，不依赖它） | `python --version`（Windows 也可用 `py --version`） |
| uv | SDK 安装脚本需要 | `uv --version` |
| SiFli SDK | **v2.5.1**（课程统一版本），板型 `sf32lb52-lchspi-ulp` | `python scripts/check_env.py` |
| AI agent 工具 | Claude Code 或 Codex 等，已登录可用 | 按各工具说明 |

## A. 安装 SDK 开发环境

> 先向教师确认 SDK 的获取方式（课程可能直接提供 v2.5.1 的拷贝）。下面的命令基于官方安装文档；官方文档更新时以官方为准，遇到报错先读错误原文再问 agent。

**获取 SDK（已有教师提供的拷贝则跳过）**：

```bash
git clone --recursive https://gitee.com/SiFli/sifli-sdk     # 含子模块，不能下载 zip
cd sifli-sdk
git checkout v2.5.1
git submodule update --init --recursive
```

**安装工具链**（在 SDK 根目录；路径用纯英文）：

- Windows（PowerShell）：`.\install.ps1`；脚本无法执行时以管理员身份运行 `Set-ExecutionPolicy RemoteSigned`。
- macOS / Linux：`./install.sh`（需先安装 `uv`，安装 `uv` 的方法见官方安装文档）。
- 国内网络较慢时，安装前可设置镜像：Windows `$env:SIFLI_SDK_MIRROR_CHINA="1"`；macOS/Linux `export SIFLI_SDK_MIRROR_CHINA=1`。

**设置环境变量**（**每个新终端都要做一次**，在 SDK 根目录）：

- Windows：`.\export.ps1`
- macOS / Linux：`. ./export.sh`（注意是 source，不是直接执行）

## B. 编译并（有板）烧录内置例程

**之后所有 SDK 相关命令都要在运行过 `export` 的那个终端里执行。**

1. 解压脚手架到一个路径不含中文和空格的目录，改名为你的项目名，进入目录。
2. 检查环境：`python scripts/check_env.py`。必需项（git、SDK、scons、ARM 编译器）全部为 ✓，SDK 版本应为 v2.5.x；缺什么按提示补。
3. 编译：`python scripts/build_firmware.py`。成功后它会打印输出目录和下载命令。
   （等价于 `cd project` 后执行 `scons --board=sf32lb52-lchspi-ulp -j8`；输出目录在 `project/build_sf32lb52-lchspi-ulp_hcpu/`。）
4. **有开发板**：USB 线接开发板的 USB-to-UART 口（不是专用 USB 功能口，且必须是数据线），运行输出目录里的 `uart_download.bat`（macOS/Linux 为 `.sh`），按提示输入串口号。用串口助手（波特率 **1000000**）打开同一串口，复位后应看到 `[course_starter] v0.1.0 boot ok`、`Hello world!`，以及循环的 `rgb -> red / green / blue`；**板载 RGB 灯同步按红、绿、蓝闪烁**。
   把串口日志存为 `evidence/T0/boot_log_<日期>.txt`，并拍一段 RGB 灯闪烁的视频或照片（`evidence/T0/` 下；大视频放网盘，在 `evidence/` 里放链接说明）。
5. **没有开发板**：只做到第 3 步，把 `build/last_build.log` 复制为 `evidence/T0/build_log_<日期>.txt`，并在日志里如实写“未烧录”。

## C. 初始化仓库与规范

1. **设置 git 身份**（只需一次）：
   ```bash
   git config --global user.name "你的姓名"
   git config --global user.email "你的邮箱"
   ```
2. **安装依赖**：`pip install -r requirements.txt`
3. **一键初始化**：`python scripts/setup_course.py`
   它会检查 SDK 环境、创建仓库、启用 `.githooks`、配置提交模板，并做首次提交。
4. **看首次提交**：`git log -1`。这条提交本身就是规范示例，对照 `docs/guides/git-workflow.md` 读懂每一项。
5. **故意写一次坏提交**（体验钩子）：随便改一个文件，执行
   ```bash
   git add -A && git commit -m "update code"
   ```
   钩子会拒绝。把拒绝输出复制到 `evidence/T0/hook_reject.txt`，在开发日志里逐条解释每个 ✗ 的含义，然后撤回或修正（`git reset` 或重新写合规的提交信息）。再试一次“标题合规、正文缺 `验证:`”的半坏提交，观察提示的差别。
6. **提交证据**：`git add evidence/T0`，提交 `hw(boot)`（有板）或 `build(firmware)`（无板），`验证:` 写证据文件路径。
7. **看初始状态**：`python scripts/check_all.py`。此时“开发日志”会 FAIL（还没写日志），这是正常的。
8. **让 agent 读规则**：在项目目录启动你的 agent，提示词用 `docs/guides/agent-collaboration.md` 第 2 节，确认它能复述规则（尤其是物理验证暂停与提交格式）。
9. **写第一篇日志**：`python scripts/new_devlog.py`，补全各小节（“AI协作记录”写你刚才让 agent 复述规则的结果，它复述得对不对；SDK 安装中遇到的问题也写进去）。
10. **提交日志**：
   ```bash
   git add docs/devlog
   git commit        # 会弹出模板，类型用 docs，scope 用 devlog
   ```
11. **填写项目名**：在 `docs/00-项目计划与里程碑.md` 写上暂定项目名与你的姓名，提交（`docs(plan)`）。

## 常见问题

| 现象 | 处理 |
|---|---|
| `git commit` 被拒绝 | 读输出里的 ✗ 项，按示例修改；这是训练的一部分 |
| `check_env` 报 scons / 编译器找不到 | 没在运行过 `export` 的终端里；重新打开终端，到 SDK 根目录运行 export 脚本再试 |
| `check_env` 报 SDK 版本不符 | 在 SDK 目录 `git checkout v2.5.1` 后重新 export |
| 编译提示子模块未初始化 | 在 SDK 根目录运行 `git submodule update --init --recursive` |
| 编译报找不到 `rgbled` 设备 / RGB 相关配置 | 检查 `project/proj.conf` 是否被改动；板型是否为 `sf32lb52-lchspi-ulp` |
| 下载时提示串口打不开 | 确认接的是 USB-to-UART 口；关掉占用该串口的串口助手；下载前先重启开发板 |
| 串口有日志但灯不亮 | 先确认灯珠供电和 PWM 配置没被改；对照 SDK 的 `example/rt_device/rgb_led`；拍下现象作为证据，不要猜 |
| 提示未找到 python | Windows 试 `py`；确认安装时勾选了 Add to PATH |
| 提交模板没弹出 | 确认 `git config commit.template` 有值；用 VSCode 作编辑器：`git config --global core.editor "code --wait"` |
| 钩子在 Windows 不执行 | 确认用 Git for Windows 提供的 Git Bash；`git config core.hooksPath` 应为 `.githooks` |
